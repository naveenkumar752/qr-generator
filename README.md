# 🌌 Aura QR | Professional QR Code Generator

Aura QR is a modern, high-quality QR code generator built with Next.js and `qr-code-styling`. It allows users to create highly customizable and visually stunning QR codes for various use cases, including URLs, WiFi, Social Media, and more.

![Aura QR Preview](https://via.placeholder.com/1200x630/2563eb/ffffff?text=Aura+QR+Generator)

## ✨ Features

- **Multi-Format Support**: Generate QR codes for URLs, Plain Text, Email, Phone, SMS, WiFi, Locations, vCards, Events, and Cryptocurrency addresses.
- **Premium Customization**: 
    - Custom colors and gradients.
    - Multiple dot styles (Square, Rounded, Extra-Rounded, Dots, etc.).
    - Customizable corner shapes and colors.
    - Adjustable error correction levels.
- **Branding & Logos**: Upload your own logo or choose from built-in social media themes (Instagram, X/Twitter, LinkedIn, Facebook, GitHub).
- **High-Resolution Export**: Download your QR codes as SVG, PNG, or JPG.
- **Real-time Preview**: Instant feedback as you design your QR code.
- **Clean UI**: A premium, minimalist interface built with modern CSS and Lucide icons.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/naveenkumar752/qr-generator.git
   cd qr-generator
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/)
- **Styling**: Vanilla CSS (Modules)
- **Icons**: [Lucide React](https://lucide.dev/)
- **QR Engine**: [qr-code-styling](https://github.com/kozakdenys/qr-code-styling)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
